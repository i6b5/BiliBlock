# 哔哩哔哩 (B站) 视频卡片净化器 | BiliBlock

一款轻量、简洁的 **B站 (bilibili) 视频卡片净化与内容过滤 Chrome / Edge 浏览器扩展**。

根据**视频标题关键词**与**UP主作者名称**自动屏蔽不感兴趣的视频卡片。支持“完全隐藏补位”与“黑卡占位防空洞”双模式，有效过滤营销号、标题党、低质推广与特定UP主，打造清爽整洁的 B站 首页与视频流浏览体验。

---

## 🌟 核心功能

- **🎯 多维度屏蔽过滤**
  - **视频标题模糊屏蔽**：自定义标题敏感词或关键词（如广告、剧透、营销、盘点等），标题命中即刻屏蔽。
  - **UP主精准完全匹配**：输入 UP 主全称严格屏蔽指定作者，精准拉黑目标账号，绝不误伤同名或名称相近的正常作者。
  - **UP主模糊屏蔽**：UP 主名称包含关键词即拦截，方便批量过滤矩阵号与营销团队。

- **⚡ 两种展示模式，自由切换**
  - **激进模式（完全隐藏，让位补齐）**：命中的视频卡片彻底消失，后续视频卡片自动平滑向前补齐，不留空白卡片，保持页面紧凑整齐。
  - **普通黑卡模式（原位占位，防布局塌陷）**：以极简黑色卡片原位覆盖过滤内容，不破坏网页原生排版结构；支持点击“临时查看”预览原视频，并可随时重新屏蔽。

- **🌐 生效范围灵活可调**
  - 支持快捷切换 **「仅首页推荐」** 或 **「全站视频卡片」**，满足不同场景的使用偏好。

- **💾 独立本地存储，规则不丢失**
  - 屏蔽词库保存于浏览器插件专属独立空间，日常清理浏览器 Cookie 和缓存不会丢失规则。
  - 支持一键 **「导出规则」** 备份为 `rules.json` 文件，并支持随时 **「导入规则」** 跨设备还原。

- **🚀 顺畅无感过滤**
  - 深度适配动态页面，浏览页面下拉无限滚动加载新视频时自动实时过滤，无需手动刷新。

## 📥 安装使用

适用于 **Chrome**、**Edge**、**Brave** 等所有 Chromium 内核浏览器。

### 本地解压安装步骤

1. **下载项目**：
   - 点击 GitHub 仓库右上角 `Code` -> `Download ZIP` 下载源码压缩包并解压到本地，或使用 `git clone` 克隆本项目。
2. **打开浏览器扩展管理页面**：
   - **Chrome 浏览器**：在地址栏访问 `chrome://extensions/`
   - **Edge 浏览器**：在地址栏访问 `edge://extensions/`
3. **开启开发者模式**：
   - 在扩展管理页右上角（或侧边栏）开启 **「开发者模式」** 开关。
4. **加载插件**：
   - 点击 **「加载已解压的扩展程序」** 按钮。
   - 在弹出的文件选择器中选择本扩展所在的文件夹目录。
5. **固定图标**：
   - 在浏览器右上角扩展拼图图标中，将「B站视频卡片净化器」固定在工具栏，方便随时配置规则。

## 🛠️ 使用指南

- **添加屏蔽词库**：
  1. 点击浏览器右上角插件图标打开设置面板。
  2. 选择 **标题模糊**、**作者完全匹配** 或 **作者模糊** 标签页。
  3. 在输入框输入关键词或作者名称，按键盘 `Enter` 回车键或点击「添加」即可即时生效。
- **调整显示效果**：
  - **开启「激进模式」**：被屏蔽的卡片彻底移除，页面自动紧凑补位。
  - **关闭「激进模式」**：保留黑色占位卡片，可点击卡片临时查看原内容。
- **切换生效范围**：
  - 在面板上方选择 **「仅首页推荐」**（仅过滤首页视频流）或 **「全站视频卡片」**（过滤相关推荐、动态、各分区卡片等）。
- **规则备份与迁移**：
  - 点击底部的 **「导出规则」** 可将当前所有规则保存为 `rules.json`。
  - 点击 **「导入规则」** 选择之前备份的 json 文件即可快速恢复。
